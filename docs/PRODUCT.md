## 1. 제품 상태

- 제품명: `dreAmIng Smart Farm` (임시명)

## 2. 한 문장 정의

설향 딸기 시설재배 농가가 농장과 작기 정보를 등록하면 현재 생육단계에 맞는 오늘의 작업을 제시하고, 완료·문제·사진·메모를 기록해 후속 작업과 이력으로 연결하는 농작업 실행관리 서비스입니다.

## 3. 문제

- 농업정보가 여러 곳에 흩어져 있다.
- 자신의 농장에 필요한 정보인지 판단하기 어렵다.
- 정보가 실제 작업으로 연결되지 않는다.
- 작업 결과와 문제 기록이 지속되지 않는다.
- 기록이 다음 작업에 활용되지 않는다.

## 4. 주요 사용자

### Primary

설향 딸기 시설재배 농업인

### Secondary

농가 운영 상태를 확인하는 작목반·농협·농업기술센터·관리 담당자

## 5. 제품 원칙

1. 오늘 해야 할 행동을 먼저 보여준다.
2. 기록은 30초 안에 끝낼 수 있도록 설계한다.
3. 공식정보와 서비스 분석을 구분한다.
4. AI보다 규칙 기반과 실제 기록 흐름을 먼저 검증한다.
5. 모든 정보를 보여주기보다 농가에 필요한 정보만 선별한다.
6. 위험 판단은 확인과 전문가 검토를 우선한다.

## 6. 첫 수직 기능 사용자 시나리오

```text
사용자가 농장 등록
→ 설향 작기와 생육단계 등록
→ 시스템이 검토된 템플릿으로 오늘의 작업 생성
→ 사용자가 오늘 화면에서 작업 확인
→ 현장에서 정상 또는 문제 결과 기록
→ 사진·메모 추가
→ 작업 이력 확인
→ 문제 발생 시 후속 확인 작업 생성
```
